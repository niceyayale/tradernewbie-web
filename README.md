# TraderNewbie - Trading Education

> 新手交易员学习与实战平台

Trading education platform for beginner traders - Learn forex, stocks and crypto

## Features

- Step-by-step trading courses for beginners
- Real-time market data and analysis
- Paper trading simulator
- Risk management calculators
- Community-driven trading signals
